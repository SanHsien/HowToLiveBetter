# Security Policy

## Scope

This repository is the SanHsien maintenance fork of [`doggy8088/HowToLiveBetter`](https://github.com/doggy8088/HowToLiveBetter). Report vulnerabilities or security issues that affect this repository via GitHub Private Vulnerability Reporting under this repository's **Security** tab.

## Supported versions

This fork actively maintains and tracks the `main` branch. Please verify any reported issues against the current `main` branch of `SanHsien/HowToLiveBetter`.

## Reporting a vulnerability

Please **do not** create a public issue for security-related reports. Instead:

- Go to **Security** → **Advisories** → **Report a vulnerability** on `SanHsien/HowToLiveBetter`.

Please include the affected commit SHA, relevant file paths, and steps to reproduce.
