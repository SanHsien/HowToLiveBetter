# 上游同步指引

本 repo 採取雙軸上游追蹤架構：
1. **直接上游（繁中在地化）**：[`doggy8088/HowToLiveBetter`](https://github.com/doggy8088/HowToLiveBetter) 的 `zh-tw` 分支。
2. **根原作上游（簡體主線）**：[`eternity4719/HowToLiveBetter`](https://github.com/eternity4719/HowToLiveBetter) 的 `main` 分支。

> [!IMPORTANT]
> **在地化最高原則**：
> 追蹤與同步上游時，**一切仍以台灣正確資料、台灣現行法規制度、官方專線與台灣繁體中文用語為唯一依歸**。
> 任何來自原作主線（`eternity4719`）的新條目或修改，若涉及大陸政策、行政審限、醫療社保機構、電話或用語，**嚴禁直接照搬**，必須經過台灣在地化查核與改寫後方得合併。

## 1. Remote 規範

```powershell
# 檢視目前 remotes
git remote -v

# 建議設定：
# origin        https://github.com/SanHsien/HowToLiveBetter.git (fetch & push)
# upstream      https://github.com/doggy8088/HowToLiveBetter.git (fetch only)
# root-upstream https://github.com/eternity4719/HowToLiveBetter.git (fetch only)
```

> [!WARNING]
> 嚴禁向 `upstream` 或 `root-upstream` 執行 `git push`！

## 2. 檢查上游更新

執行自動化雙軸上游增量檢查：

```powershell
# 檢查直接上游（doggy8088）
python tools/check_upstream_updates.py --baseline tools/upstream_baseline.json

# 檢查根原作上游（eternity4719）
python tools/check_upstream_updates.py --baseline tools/upstream_root_baseline.json --output upstream-root-review-report.md
```

或直接執行一鍵門禁：
```powershell
pwsh -NoProfile -File tools\dev_check.ps1
```

## 3. 同步與在地化裁決步驟

當決定同步上游變更時：

1. **抓取上游**：
   ```powershell
   git fetch upstream zh-tw
   git fetch root-upstream main
   ```
2. **差異審查**：
   - 查看上游新 commit 與 PR 討論。
   - 評估是否屬於通用健康科學、長壽研究或全球文獻（可評估引入）。
   - 若屬於在地法規、政府給付或制度，嚴格對照台灣主管機關公告（衛福部、勞動部、司法院等）。
3. **進行移植與在地化改寫**：
   - 繁體字詞校正（參照 `scripts/zh-tw/vocab.mjs` 與既有繁中規範）。
   - 急難專線與審限校驗（符合台灣 110/119/1925 與台灣民刑訴訟實務）。
4. **更新水位記錄**：
   - 若審查直接上游，更新 `tools/upstream_baseline.json`。
   - 若審查根原作上游，更新 `tools/upstream_root_baseline.json`。
5. **記錄決策於 [`docs/DECISIONS.md`](DECISIONS.md)**。
6. **本機全量門禁驗收**：
   ```powershell
   pwsh -NoProfile -File tools\dev_check.ps1
   ```
7. **提交並推送到 `origin/main`**。
